# BotFlow Builder — инструкция для ИИ-ассистента

Единый источник инструкций для всех ИИ-ассистентов проекта — @AGENTS.md.
Он подключается в контекст автоматически, поэтому правьте **AGENTS.md**, а не этот файл.

Раньше инструкции дублировались в двух файлах и разошлись: CLAUDE.md предлагал
`npm run dev` и обещал вход в админку без пароля, хотя упрощённый вход давно
вынесен в отдельный скрипт `npm run dev:local-login`.
